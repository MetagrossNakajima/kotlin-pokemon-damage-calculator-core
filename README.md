# kotlin-pokemon-damage-calculator-core

ポケモンのダメージ計算用 Kotlin/JVM ライブラリ。

## 開発環境

- JDK 26（mise）
- Kotlin 2.4.21
- Gradle 9.7.0（Gradle Wrapper）
- kotlin.test / JUnit 5

## セットアップ

[mise](https://mise.jdx.dev/getting-started.html) をインストールし、リポジトリのルートで実行します。

```sh
mise trust
mise install
mise run build
```

## 開発コマンド

```sh
mise run build  # ビルド
mise run test   # テスト
mise run check  # 検証
mise run clean  # ビルド成果物の削除
```
